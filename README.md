# taiwan-uric-acid-gout-database

台灣痛風與高尿酸飲食資料庫。收錄台灣常見食物的嘌呤含量分級、血尿酸診斷標準、
降尿酸飲食策略，數據來源為衛福部食藥署 TFND、USDA FoodData Central 及同行評審研究。

## 為什麼建立這個資料庫

台灣痛風盛行率約 6.24%（男性），是全球最高之一（Kuo et al., 2015 PMID: 25580703）。
痛風急性發作極為疼痛，而飲食管理是預防發作的核心策略。然而，現有中文嘌呤含量表
多為舊版（1980–1990 年代）且缺乏台灣在地食物資料。本資料庫整合最新數據，
提供結構化、可查詢的格式，供開發者和研究者使用。

## 資料說明

| 檔案 | 說明 |
|------|------|
| `data/purine-content-foods.json` | 台灣常見食物嘌呤含量（mg/100g），分四級：極高/高/中/低 |
| `data/uric-acid-targets.json` | 血尿酸正常值、高尿酸症/痛風診斷切點、治療目標（台灣風濕病學會） |
| `data/dietary-strategies.json` | 降尿酸飲食策略（水化、限酒精、限果糖、嘌呤分級建議） |

## 嘌呤分級標準

| 等級 | 嘌呤含量（mg/100g） | 建議 |
|------|---------------------|------|
| 極高 | ≥ 150 | 急性發作期完全避免 |
| 高 | 75–149 | 緩解期每日 ≤ 1 份 |
| 中 | 25–74 | 適量攝取 |
| 低 | < 25 | 可自由攝取 |
