# Taiwan Uric Acid & Gout Database（台灣痛風與高尿酸飲食資料庫）

台灣痛風與高尿酸血症（Hyperuricemia）飲食管理結構化資料庫。收錄台灣常見食物的嘌呤含量分級、高尿酸症的全身代謝危害、血尿酸診斷標準，以及降尿酸飲食策略。

## 為什麼台灣需要這個資料庫

台灣是全球高尿酸血症盛行率最高的地區之一：

| 指標 | 台灣數據 | 全球比較 |
|------|---------|---------|
| 高尿酸血症盛行率 | 約 25–30%（男性 > 女性） | 全球前三 |
| 痛風盛行率 | 約 6.24%（男性） | 全球最高之一 |
| 高尿酸但無痛風 | 高尿酸患者中約 80–90% 從未發作痛風 | 代謝風險被低估 |
| 年輕化趨勢 | 30 歲以下痛風患者比例持續上升 | 與飲料消費相關 |

**最關鍵的認知：**「沒有痛風就不用擔心高尿酸」是一個危險的錯誤觀念。高尿酸血症（即使無症狀）是**心血管疾病、慢性腎臟病和胰島素抗性的獨立危險因子**。

## 高尿酸的全身代謝危害

```
尿酸每上升 1 mg/dL
    ↓
心血管事件風險 +8–12%
慢性腎臟病進展加速
NLRP3 炎症小體激活 → 全身慢性發炎
血管內皮一氧化氮（NO）合成受阻
```

**台灣特別值得注意的關聯：**
- 台灣洗腎率全球最高 → 尿酸性腎病是 CKD 進展的獨立因素
- 台灣代謝症候群盛行率高 → 高尿酸和代謝症候群雙向關聯（高果糖攝取同時驅動兩者）

## 台灣常見食物嘌呤含量分級

| 等級 | 嘌呤含量（mg/100g） | 建議 |
|------|---------------------|------|
| 極高（⚠️ 急性期禁止） | ≥ 150 | 急性發作期完全避免 |
| 高（⚠️ 緩解期限量） | 75–149 | 緩解期每日 ≤ 1 份 |
| 中（✓ 適量可食） | 25–74 | 適量攝取 |
| 低（✅ 自由攝取） | < 25 | 可自由攝取 |

### 台灣飲食中的高嘌呤食物

**極高嘌呤（≥ 150 mg/100g）：**

| 食物 | 嘌呤（mg/100g） | 台灣情境 |
|------|---------------|---------|
| 雞肝、豬肝 | 300–400 | 滷味攤常見 |
| 小魚乾（丁香魚） | 200–400 | 台灣早餐粥、鹹粥配料 |
| 蚵仔（生） | 150–200 | 蚵仔煎、海鮮火鍋 |
| 火鍋湯底（久煮） | > 150（湯中濃縮） | 台灣火鍋文化的最大風險 |
| 酵母粉 | > 500 | 某些健康補充品 |

**高嘌呤（75–149 mg/100g）：**

| 食物 | 嘌呤（mg/100g） | 台灣情境 |
|------|---------------|---------|
| 牡蠣（蚵仔） | 107 | 海鮮常見 |
| 草蝦 | 138 | 台灣火鍋、燒烤 |
| 花枝（魷魚） | 89 | 鹽酥雞配料 |
| 鯖魚 | 128 | 台灣常見魚類 |
| 豬腳 | 93 | 台灣傳統食物 |
| 香菇（乾） | 100–150 | 注意：乾香菇比新鮮濃縮 3–4 倍 |
| 豆腐 | 55–75 | 適量可食 |
| 毛豆 | 80 | 啤酒配菜 |

> **重要：蔬菜高嘌呤（香菇、蘆筍、花椰菜）的代謝路徑和動物嘌呤不同，研究顯示蔬菜高嘌呤和痛風風險無顯著關聯（Choi et al. 2004）。蔬菜不需要因嘌呤高而刻意迴避。**

## 台灣特有的高風險飲食因素

| 因素 | 說明 | 量化影響 |
|------|------|---------|
| 手搖飲（高果糖玉米糖漿） | 果糖在肝臟代謝時大量消耗 ATP → AMP → 尿酸 | 一杯全糖珍奶果糖可顯著升高血尿酸 |
| 啤酒 | 同時含酒精（減少腎臟尿酸排泄）+ 酵母嘌呤 | 比其他酒類痛風觸發效果更強 |
| 火鍋湯底 | 久煮後嘌呤濃縮，一碗湯嘌呤量可超過主食材 | 台灣痛風患者最常見的急性發作觸發 |
| 內臟類食物 | 豬肝、腰子、雞心 | 嘌呤濃度最高的食物類別 |
| 海鮮快炒文化 | 蝦蟹貝類高頻攝取 | 台灣海鮮文化相較歐美更高頻率 |

## 降尿酸飲食策略（有科學證據）

| 策略 | 機制 | 效果 |
|------|------|------|
| **減少液態果糖** | 抑制 De Novo 尿酸合成 | 最有效的單一飲食改變 |
| **增加飲水量** | 促進腎臟尿酸排泄 | 每日 2,000–3,000 mL；目標尿液淡黃色 |
| **低脂乳製品** | 乳清蛋白促進腎小管尿酸分泌 | 研究顯示可降低血尿酸 |
| **維生素 C** | 競爭性抑制腎小管尿酸重吸收 | 每日 500–1,000 mg 維生素 C，輕度降尿酸 |
| **減少酒精（尤其啤酒）** | 酒精代謝競爭腎臟排泄 | 戒啤酒效果最顯著 |
| **限制肉類內臟和高嘌呤海鮮** | 減少嘌呤外源性負荷 | 緩解期每日 < 150g 高嘌呤動物蛋白 |
| **咖啡（黑咖啡，適量）** | 觀察性研究顯示負相關（機制未明） | B 級證據 |

## 相關工具（Interactive Tools）

本資料庫的台灣痛風與高尿酸數據，已整合至 [MetaboLab](https://metabolab.tw) 的互動工具中：

- 🦐 **[痛風普林計算機](https://metabolab.tw/calculators/gout-purine)**：評估你的每日飲食嘌呤總攝取量，識別哪些台灣常見食物正在悄悄升高你的血尿酸，並獲得個人化的嘌呤限制建議。
- 💧 **[每日飲水量計算機](https://metabolab.tw/calculators/water-intake)**：充足飲水是腎臟排泄尿酸最有效且免費的非飲食介入——計算你的個人化每日飲水目標（台灣夏季高溫需求更高）。
- 🔢 **[熱量換算工具](https://metabolab.tw/calculators/calorie-converter)**：量化台灣手搖飲和含糖飲料的果糖含量，理解「液態果糖 = 直接驅動尿酸合成」的代謝現實。
- 📊 **[TDEE 計算機](https://metabolab.tw/calculators/tdee)**：體重管理（每下降 5–10%）可顯著降低血尿酸，設計合理的熱量缺口是降尿酸的長期策略之一。
